# 🕷️ Mobile Game Testing - Spider Fighter

## 📚 Описание проекта

Тестирование мобильной игры **Spider Fighter** было проведено в рамках практического задания по проверке игровых билдов на Android.
Тестирование выполнялось вручную на эмуляторе **Android Studio**, с целью выявить ошибки в интерфейсе, логике игры и пользовательском опыте.

## 🧪 Детали тестирования

Основные направления тестирования:

* UI и функциональные кнопки главного экрана;
* корректность сохранения прогресса и начисления наград;
* стабильность после просмотра рекламы;
* поведение AI противников и возрождение персонажа;
* работа с локализацией и настройками.

## 🐞 Основные результаты

В ходе тестирования были выявлены дефекты различной критичности — от неработающих кнопок и нарушений логики возрождения до утраты прогресса и отсутствия отклика интерфейса.

Ключевые проблемы:

* неактивные кнопки *“+”* и *“SHOP”*;
* отсутствие реакции на смену графики и языка;
* неработающая кнопка *“Restore Purchases”*;
* возможность вызвать **debug-панель** тройным нажатием на экран;
* реклама без возможности закрытия и без начисления награды;
* потеря прогресса при выходе из игры;
* визуальные и логические ошибки при возрождении;
* пассивные враги на уровнях с огнестрельным оружием.
