# 🧾 Регрессионный чек-лист ЛигаМаркет

## 📚 Описание проекта

Регрессионный чек-лист для тестирования платформы ЛигаМаркет разработан и поддерживается в рамках работы над крупным e-commerce проектом. Основная цель — обеспечить стабильность продукта при каждом релизе, покрывая все ключевые функциональные области и сценарии использования.
Чек-лист постоянно актуализируется под новые требования, содержит более 1400 проверок и охватывает как клиентскую часть, так и административную панель. Ведется в табличном формате с группировкой по функциональным модулям и регулярно пересматривается для поддержания релевантности.

## ✅  Что покрывает чек-лист

Основные разделы проверок включают:
* Клиентская часть: личный кабинет, корзина, оформление заказа, каталог товаров, фильтры, поиск.
* Административная панель: управление товарами, категориями, промокодами, ПВЗ, отчетами.
* API и интеграции: тестирование внешних систем (1С, Giftery, СДЭК, Printio, эквайринг).
* Платежные сценарии: ЧК, онлайн-оплата, внутренняя валюта, промокоды.
* Ролевая модель: проверка прав доступа для всех ролей (администратор, контент-менеджер, оператор, ассистент и др.).
* Классификационный каталог, словарь синонимов, справочник тарифов СДЭК и другие системные модули.

## 📄 Результат

В результате оформлен единый регрессионный чек-лист, объединяющий проверки всего функционала ЛигаМаркета. Используется для контроля качества перед каждым релизом, помогает быстро находить регрессии, экономить время на тестировании и систематизировать процесс проверки продукта.
